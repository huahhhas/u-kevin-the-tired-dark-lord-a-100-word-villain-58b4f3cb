# u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb

A 100-word monologue spoken by a fantasy villain who is secretly just very tired. The Dark Lord of Vhaldor has spent three centuries raising an army of the dead, and the dead will not peel potatoes — so the siege waits until after a lunch that will never come.

## Run it

```sh
python3 main.py
```

It writes the monologue to `/output/entry.txt` (exactly 100 words, 529 characters).
